# Escape Road Game

A fast-paced, 2D arcade-style survival game built using Vanilla JavaScript and HTML5 Canvas. Navigate through obstacles, collect power-ups, and survive as long as possible to achieve a high score.

## 🎮 How to Play
- **Objective:** Dodge incoming obstacles and stay on the road for as long as possible.
- **Controls:** Use the **Spacebar** or **Up Arrow** to jump and avoid hazards.
- **Power-ups:**
  - 🛡️ **Shield:** Protects you from a single collision.
  - ⚡ **Speed Boost:** Increases your movement speed and score multiplier.

## 🛠️ Features
- **Dynamic Physics:** Implemented gravity and collision detection logic from scratch.
- **Parallax Background:** Smooth scrolling layers to create a sense of depth and speed.
- **Increasing Difficulty:** The game speeds up and obstacles become more frequent the longer you survive.
- **Responsive Canvas:** Designed to run smoothly in modern web browsers.

## 💻 Tech Stack
- **Frontend:** HTML5, CSS3
- **Logic:** Vanilla JavaScript (ES6+)
- **Rendering:** HTML5 Canvas API

## 📂 Project Structure
- `index.html`: The entry point and game container.
- `script.js`: Contains the core game engine, player classes, and game loop logic.
